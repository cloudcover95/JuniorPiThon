# JuniorPiThon rails

Operating rules for this repo, kept in step with the JuniorLLM / JuniorOS rails.

- Additive only: new files and commits; never delete, never force-push.
- No GitHub Actions workflows.
- No model pulls; work with what is already local.
- Any local service binds to `127.0.0.1` only.
- One slice per run: one pull, one additive file, one push.

See also: `docs/LOCAL.md`, `docs/HOME.md`, `docs/DECK_CHANNELS.md`.
