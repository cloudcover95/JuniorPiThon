# JuniorPiThon

**Edge-Native Python Development & Runtime Environment**

JuniorPiThon is a lightweight, sovereign Python IDE and runtime optimized for Raspberry Pi and Apple Silicon edge nodes. It powers local development, orchestration, and integration across the JuniorCloud LLC stack.

## Role in the Ecosystem

| Component       | Usage of JuniorPiThon                              |
|-----------------|----------------------------------------------------|
| **JuniorHome**  | Local development and scripting environment        |
| **JuniorStock** | Custom strategy development and backtesting        |
| **crispy-mouse**| Low-level scripting and macro development          |
| **JuniorOmega** | Spatial computing script development               |

JuniorPiThon is designed to be the everyday development tool for building and maintaining the full sovereign edge stack without relying on cloud IDEs.
